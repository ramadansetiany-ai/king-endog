📌 Cara Cepat Membuat Database Firebase Gratis (2 Menit):

  1. Buka console.firebase.google.com dan login dengan akun Google.
  2. Klik "Add project", beri nama misal: kandang-ayam (Analytics boleh dimatikan).
  3. Di menu samping kiri, klik Build > Firestore Database > klik Create database > pilih Start in test mode > Next > Enable.
  4. Di samping tulisan "Project Overview" (kiri atas), klik ikon gear ⚙️ > pilih Project settings.
  5. Scroll ke bawah ke bagian "Your apps", klik ikon web </> > masukkan nama app > klik Register app.
  6. Salin seluruh kode const firebaseConfig = { ... }; lalu tempel di kotak di atas!
